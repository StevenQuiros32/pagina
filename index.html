Soy un desarrollador especializado en aplicaciones móviles y bases de datos, con formación técnica en el CTP Carlos Pascua Zúñiga. Me impulsa la eficiencia: cada proyecto que tomo lo termino antes del plazo, integrando funciones que superan las expectativas iniciales.

Tengo experiencia en desarrollo full-stack — desde la lógica de negocio y gestión de bases de datos con SQL Server, hasta interfaces web con HTML, CSS y JavaScript. En el lado móvil trabajo con Kotlin (Jetpack Compose), Java y el Android SDK.

Complemento mis habilidades de desarrollo con certificaciones de Cisco en redes y ciberseguridad, lo que me da una visión completa del entorno donde corre el software que construyo.
